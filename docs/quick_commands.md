# Quick Commands

## Git Setup

### Store Git Credentials Globally

```bash
git config --global credential.helper store
```

## Clone OpenAudio

### Clone Develop Branch

```bash
git clone -b develop https://github.com/ventii-inc/openaudio.git
```

### Clone and Enter Directory

```bash
git clone -b develop https://github.com/ventii-inc/openaudio.git && cd openaudio
```
